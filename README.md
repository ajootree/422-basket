# 생태 바구니

초등 4학년 과학 ‘생물과 환경’ 수업용 사진 분류 게임입니다.

- 실제 생물 사진 81종: 생산자 28종, 소비자 42종, 분해자 11종.
- 쉬움·보통·어려움마다 생산자 → 소비자 → 분해자 3라운드. 하트 없이 연습합니다.
- 생태 마라톤: 하트 5개, 제한 시간·목표 개수 없음. 15~20초가 지나고 3개 이상 올바르게 담으면 3초 예고 뒤 바구니 역할이 무작위로 바뀝니다.
- 마라톤 최고 점수는 현재 기기·브라우저에만 저장합니다. 공용 기기에서는 다른 학생과 같은 최고 점수가 표시됩니다. 브라우저 데이터를 지우면 초기화됩니다.
- 가입, 이름·학교 입력, 전국·학교 랭킹, 서버 API, Supabase 연결이 없습니다.
- 첫 로딩 때 사진을 내려받으면 같은 화면에서 인터넷이 끊겨도 계속 플레이할 수 있습니다. 오프라인 상태에서 최초 접속하거나 새로고침하는 것은 보장하지 않습니다.

## 배포

빌드나 환경 변수 없이 폴더 전체를 정적 호스팅에 올리면 됩니다. GitHub Pages는 Settings → Pages → Deploy from a branch → main / (root)를 선택합니다. Vercel은 Framework Preset을 Other, 별도 Build Command 없이 루트를 배포합니다.

## 자료 및 사진

아이스크림미디어 2022 개정 4학년 2학기 과학 교과서·지도서의 공개 자료 및 지학사 공개 발췌본을 참고했습니다. 지학사 지도서 전체 목록까지 대조한 것은 아닙니다. 교과서 원문·그림은 포함하지 않았습니다. 사진별 원작자·원본 링크·이용 조건은 [사진 출처](photo-credits.html)에 있습니다.

## 검증

9개 일반 라운드, 마라톤 하트·점수·전환·일시정지, 모바일 화면, 최고 점수 재접속 유지, 로딩 후 오프라인 플레이, 외부 API 요청 없음 확인.

게임과 사진은 총 약 3.9MB입니다. 5,000명이 캐시 없이 한 번씩 모두 내려받으면 약 20GB, 10,000명은 약 39GB입니다. 반복 접속 시 캐시 사용량에 따라 달라집니다. GitHub Pages의 월 100GB 소프트 대역폭 한도 및 순간 요청 제한은 [공식 문서](https://docs.github.com/en/pages/getting-started-with-github-pages/github-pages-limits)를 참고하세요.
